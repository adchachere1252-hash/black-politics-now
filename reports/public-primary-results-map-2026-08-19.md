# Public U.S. Primary Results Map

**Published placement:** Homepage → **Interactive Election Map** → **Primary** tab (desktop website)

## Purpose and display boundary

The Primary tab is a new public map layer for the source-backed August 18, 2026 primary and special-election outcomes. It is intentionally distinct from Senate, House, Governor, and Black Political Representation views. Participating states render in teal, a nonpartisan outcome color; all other states use the existing no-data fill. The tab title explicitly states that its records are **not general-election calls**.

| State | Current map status | Source-link detail |
| --- | --- | --- |
| Florida | Projected primary result | Governor and Senate nominees; FL-7 incumbent result |
| Alaska | Ongoing top-four count | Reported Senate, House, and governor leaders; not certified |
| Wyoming | Projected primary result | Major-party U.S. Senate nominees |
| California | Unofficial special-election result | CA-14 county return, clearly limited to the district |

Clicking a colored state opens a result panel with the contest-level outcome, explicit status, update context, and source link. The general-election rating colors, DDHQ call fields, certified archive, and final-election-only ticker are not altered by this layer.

## Responsive behavior

The map tab is visible within the desktop homepage’s Interactive Election Map. The mobile app preserves its user-requested map-free stacked homepage, so it does not present an unusable compressed U.S. map. Desktop and mobile visual checks confirmed the tab appears without crowding the desktop controls and the mobile layout remains unchanged.
