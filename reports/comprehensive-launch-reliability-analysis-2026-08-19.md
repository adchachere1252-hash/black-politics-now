## Admin workflow and homepage synchronization

The Admin **Prepare evidence package** action has been independently smoke-tested as a working replacement for the unavailable AI task. It creates a private, reviewable source package and a pending `source_watch` recommendation without publishing data or calling a language model. The Portrait Review workspace provides its own dependable official-source method: select a candidate, open a curated official-source lead, submit secure image and provenance URLs, then approve or deny the package before it can update a public portrait.

Admin election and Black Representation saves do connect to the homepage. The protected update mutations write the same underlying `election.cbc` and `election.blackRepresentationElections` data contracts consumed by the public homepage. The homepage treats this data as stale after 15 seconds and refetches it every **60 seconds**, including in the background. A saved correction therefore reaches an open public homepage without a manual deployment or a browser refresh at the next refresh interval.
