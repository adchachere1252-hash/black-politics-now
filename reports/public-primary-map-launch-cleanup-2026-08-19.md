# Launch Cleanup: Public Primary Map Removed

**Completed:** August 19, 2026 (EDT)

The public homepage’s Interactive Election Map now presents only **Black Reps**, **Governor**, **House**, and **Senate** views. The Primary tab, primary-specific state search, primary legend, primary details dialog, primary summary labels, and August 18 primary-map copy have been removed from the launch-facing homepage.

The general-election map remains unchanged in function: its rating legend, state search, candidate detail dialogs, results ticker boundary, and Black Representation view remain available. Verified primary records and source packages remain in the project codebase as internal evidence; they are no longer imported into or bundled with the public homepage map experience.

Desktop verification confirms the public toolbar now reads **Black Reps · Governor · House · Senate** and presents general-election explanatory copy. The mobile homepage remains map-free as previously designed.
