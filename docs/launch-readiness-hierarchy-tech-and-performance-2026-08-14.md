# Launch-Readiness Hierarchy, Tech Sourcing, and Candidate Performance

## Public purpose and editorial discovery

The public homepage now introduces the platform with a concise purpose statement: **“Black Politics Now connects Black political reporting to the races, institutions, and historical context shaping power today.”** It reinforces the reporting-to-record relationship without changing the original WordPress newsroom’s role as the editorial home.

The Daily Brief and Archive now offer a stronger first decision: the latest complete Daily Brief and latest reporting are featured before the longer collections. Both screens add topic or category controls to help a reader identify what changed today without scrolling through a flat list.

## Needs Decision Now

The protected Admin Overview contains a compact **Needs Decision Now** lane. It aggregates the review work that needs an explicit editorial or data decision—pending agent proposals, active triage, and task alerts—without creating a public action path. The lane is an attention-management layer, not a publishing tool.

## Provenance-first portrait discovery

Portrait Review now requires a named current gap and provides official-source discovery leads. The administrator can use the official-campaign search and FEC record links, paste a credible **Provenance URL / official research lead**, and send only that supplied lead into a bounded private research task. The agent receives the lead as evidence context; it cannot invent a portrait URL or apply an image.

## Tech News source transparency

Tech News segments now carry `sourceLinks` and `sourceVerifiedAt` metadata. The Daily Brief generator persists its verified source set for future Tech segments; a controlled backfill recovered source markers for the retained August 12–14 Tech scripts. The public Podcast page shows the sources when an episode is expanded, labels the verification date, and clarifies that source markers are excluded from spoken audio.

## Democratic and Republican candidate performance

The protected Command Center now includes a **Live returns** section for races with stored reporting or vote totals. It displays Democratic and Republican names, vote totals, vote share, reporting percentage, lead margin, and a clear **Preliminary** or **Called** status. It does not fabricate live percentages: scheduled races with no stored returns are omitted from the display.

> All of these improvements preserve the platform’s public-action boundary. A source link, an agent proposal, a performance panel, or an urgent queue item is evidence for review—not an automatic change to WordPress, portraits, election results, public alerts, or race calls.
