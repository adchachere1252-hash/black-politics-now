# Original Black Politics Now WordPress Newsroom: Visual Recommendation

## Recommendation

Keep the current WordPress newsroom recognizably intact. Its strongest qualities are already clear: the compact category navigation, large condensed headlines, visual article grid, and black-and-white editorial confidence. The visual concept recommends a **measured elevation**, not a replacement or a platform rebuild.

> The WordPress site remains the reporting home. The Election Map is its clearly marked live-service destination.

## Recommended homepage hierarchy

| Area | Preserve | Elevate |
|---|---|---|
| Header | Existing Black Politics Now wordmark and category rail | Add one durable, clearly labeled **Election Map** item beside Elections; use a restrained gold active state rather than an oversized banner. |
| Breaking-news strip | Existing compact topical links | Add a dark election-aware ticker with a small blue live indicator and an editorial `ELECTIONS` label. |
| Lead reporting | Image-led main story with bold condensed headline | Use one clear lead story, two supporting stories, and stronger metadata to improve scanning without turning the page into a dashboard. |
| Live-service destination | Current election-category context | Place a horizontal `ELECTION MAP — Live U.S. Race Center` rail below the lead stories. It should display a tiny U.S. outline, restrained red/blue/purple rating ticks, and one gold **Open Election Map** button. |
| Top News | Existing multi-column reporting grid | Retain the grid, but use stronger card hierarchy, consistent category tags, and slightly more whitespace. |
| Footer | Existing broad category directory | Add a concise `Platform` group: Election Map, World Elections, Historical Atlas, Daily Brief, and Research Desk. |

## The Election Map return path

The WordPress header should include a permanent **Election Map** link. The homepage should reinforce it with the small horizontal service rail in the visual concept, positioned immediately below the lead coverage. Both should direct readers to the Black Politics Now platform home, where the live map is the central feature.

This uses the map as a utility readers can enter from a relevant story, rather than competing with reporting or making the WordPress site look like software. The callout should not replace the existing Elections category; it should clarify the distinction between **Election reporting** and the **live map service**.

## Theme treatment

The recommended default retains the original white editorial canvas and deep black lead-story band. Navy blue stays attached to reportage metadata, category underlines, and live indicators. Gold appears only on high-confidence actions such as the Election Map button, active navigation, and verified-status details. Purple is reserved for a toss-up marker inside the map rail, preserving the platform’s established race-rating meaning.

## What not to change

Do not replace the category navigation with a product dashboard, turn every article card into a large rounded panel, or make the World globe and Atlas compete with the lead reporting. The homepage should still feel like a working political newsroom first. World Elections, Historical Atlas, and the Daily Brief belong in a narrow “Platform” rail or footer grouping until their editorial relevance is specific to a story.
